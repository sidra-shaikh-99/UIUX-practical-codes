## 🛠️ Requirements

### For XML (Android) Practicals:
- Android Studio
- Android SDK (API 21+)
- Java JDK 8+

### For Dart (Flutter) Practicals:
- Flutter SDK
- Android Studio or VS Code
- Flutter & Dart plugins installed

---

## 🚀 How to Run

### ▶️ XML Files (1a, 1b, 2a, 2b)
1. Open Android Studio
2. Create a new project → Empty Activity
3. Go to res/layout/activity_main.xml
4. Delete existing code
5. Paste the code from the respective .xml file
6. Click Run ▶️ to see the output

### ▶️ Dart Files (16a to 16g)
1. Open VS Code or Android Studio
2. Create a new Flutter project: flutter create my_app
3. Go to lib/main.dart
4. Delete existing code
5. Paste the code from the respective .dart file
6. Run the app: flutter run
